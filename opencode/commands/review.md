Actúa como code reviewer senior. Revisa el código en el scope indicado o el proyecto completo.

Evalúa:
1. **Arquitectura** - ¿El diseño es sólido? ¿Acoplamiento excesivo?
2. **Performance** - ¿Cuellos de botella potenciales? ¿Consultas N+1?
3. **Seguridad** - ¿Inyecciones, validación de inputs, auth?
4. **Mantenibilidad** - ¿Código claro? ¿Tests? ¿Duplicación?
5. **Buenas prácticas** - ¿Sigue estándares del lenguaje/framework?
6. **Errores** - ¿Bugs evidentes? ¿Manejo de errores adecuado?

Da sugerencias concretas con ejemplos de código si aplica.
Prioriza los hallazgos por criticidad: 🔴 Alto / 🟡 Medio / 🟢 Bajo.
